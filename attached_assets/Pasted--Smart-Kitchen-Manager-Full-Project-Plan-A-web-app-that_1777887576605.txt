# Smart Kitchen Manager — Full Project Plan

> A web app that tracks your kitchen stock, suggests meals based on available ingredients, and auto-generates a shopping list for missing or low items.

---

## Project Overview

| Field | Detail |
|---|---|
| Project Name | Smart Kitchen Manager |
| Type | Web Application (PWA) |
| Target Users | Individuals and families who cook at home |
| Primary Goal | Eliminate daily "what should I cook?" decision fatigue |
| Platform | Web (desktop + mobile responsive) |
| Tech Stack | React + Vite, Node.js/Express, PostgreSQL, Claude AI API |

---

## Problem Statement

Every day, home cooks face the same three problems:

1. **"What should I cook today?"** — No easy way to see what meals are possible with current stock.
2. **"What do I need to buy?"** — Shopping lists are made from memory, leading to forgotten items or overbuying.
3. **"What do I have?"** — No visibility into pantry stock until something runs out.

This app solves all three with a single, simple interface.

---

## Core Features

| # | Feature | Description |
|---|---|---|
| 1 | Kitchen Stock Manager | Add, edit, remove ingredients with quantity and unit tracking |
| 2 | Smart Status Tracking | Auto-mark items as In Stock / Low / Out based on quantity |
| 3 | Meal Suggestion Engine | Suggest meals based on available ingredients with match % |
| 4 | AI-Powered Suggestions | Use Claude API to suggest creative meals and recipes |
| 5 | Shopping List Generator | Auto-generate list from low stock + missing recipe ingredients |
| 6 | Manual Shopping Items | Let users add custom items to the shopping list |
| 7 | Recipe Detail View | Step-by-step cooking instructions for each suggested meal |
| 8 | User Accounts | Login/signup to sync data across devices |
| 9 | PWA Support | Install on mobile like a native app, works offline |
| 10 | Family/Multi-user | Share kitchen stock with household members |

## Key Algorithm: Meal Suggestion Logic

```javascript
// matchRecipes.js
function getSuggestions(stock, recipes) {
  const inStock = stock
    .filter(item => item.quantity > 0)
    .map(item => item.name.toLowerCase());

  return recipes
    .map(recipe => {
      const required = recipe.ingredients.map(i => i.name.toLowerCase());
      const optional = recipe.ingredients
        .filter(i => i.is_optional)
        .map(i => i.name.toLowerCase());

      const have = required.filter(i => inStock.includes(i));
      const missing = required.filter(i => !inStock.includes(i));
      const matchScore = have.length / required.length;

      return { ...recipe, have, missing, matchScore };
    })
    .filter(r => r.matchScore > 0)
    .sort((a, b) => b.matchScore - a.matchScore);
}
```
